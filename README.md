# Venti1112 的主题包 — 蔚蓝档案 Blue Archive 主题

一款为 [EchoMusic](https://github.com/hoowhoami/EchoMusic) 播放器设计的蔚蓝档案（Blue Archive）主题插件，包含点击粒子特效、角色壁纸、字体替换与毛玻璃 UI 美化。

## 功能

### ✨ 点击粒子特效 (BASpark)
- 点击页面任意位置触发粒子爆炸与光环波纹
- 鼠标拖拽产生发光线拖尾
- 可自定义颜色（预设：蔚蓝 / 樱花 / 薄荷 / 薰衣草 / 夕阳 / 纯白 + 取色器）
- 可调节：粒子大小、透明度、动画速度、拖尾长度
- 始终显示拖尾模式

### 🖼️ 角色壁纸
内置 7 张蔚蓝档案主题壁纸：

| 壁纸 | 角色 |
|------|------|
| Arona | 阿罗娜 |
| PV 2nd / 3rd / 4th | 官方 PV 艺术图 |
| 白子骑行 | 白子（越野摩托） |
| 白子骑行 2 | 白子（越野摩托 2） |
| 优香与诺亚 | 优香 × 诺亚 |

- 支持上传自定义壁纸（自动缩放至 1920px 以内）
- 壁纸模糊度与暗度调节
- 歌词页背景替换为壁纸
- 悬浮磨砂侧边栏（可调模糊度）
- 播放器栏磨砂玻璃效果
- 卡片磨砂（页面卡片、面板、吸顶工具栏）
- 弹窗磨砂（对话框、抽屉、右键菜单、Toast、搜索建议）
- 表头壁纸对齐：吸顶工具栏实时跟随视口背景，无错位

### 🔤 字体替换
- **Blueaka（内置）** — 来自 [kivo.wiki](https://kivo.wiki)，含 Regular (400) 和 Bold (700) 两个权重，覆盖中日韩字符集
- **系统字体** — 使用本机已安装的字体
- **自定义字体文件** — 支持 ttf / otf / woff / woff2

### 🎨 毛玻璃透明度系统
- 表面透明度统一控制（主界面、侧边栏、卡片、弹窗、播放器）
- 模糊度分组独立调节（侧边栏、播放器、卡片、弹窗）
- 深色/浅色模式自适应侧边栏与播放器底色
- MutationObserver 实时拦截 Vue 重渲染，保持透明背景不被覆盖

## 安装

1. 打开 EchoMusic 设置 → 插件
2. 选择「从文件夹加载插件」
3. 选择本主题包所在目录
4. 在插件设置面板中按需调整各选项

## 要求

- EchoMusic 版本 **>= 2.2.6-beta.9**

## 配置项

| 分类 | 设置 | 说明 |
|------|------|------|
| 粒子 | 启用 / 颜色 / 大小 / 透明度 / 速度 / 拖尾长度 / 始终拖尾 | 点击特效参数调整 |
| 壁纸 | 启用 / 选择壁纸 / 上传自定义 / 模糊度 / 遮罩暗度 | 背景与视觉效果 |
| 壁纸 | 替换播放页背景 / 悬浮侧边栏 / 侧边栏模糊度 | 壁纸样式选项 |
| 壁纸 | 播放器模糊度 / 卡片磨砂 / 卡片模糊度 / 弹窗磨砂 / 弹窗模糊度 | 毛玻璃效果分组 |
| 字体 | 启用 / 来源选择 / 系统字体选择 / 自定义字体文件 | 全局字体替换 |
